# Как работает GUI-казино

## Состав

- `CasinoPlugin` инициализирует экономику, меню и таймер одного общего раунда.
- `RouletteGame` хранит `BetBook`, фазу и результат. Синхронный Bukkit-таймер (`runTaskTimer`) переключает `BETTING → SPINNING → RESULT → BETTING`. Результат от 0 до 36 выбирается один раз при начале прокрутки; анимация лишь подсвечивает числа в порядке `WheelNumbers.EUROPEAN_ORDER`.
- `CasinoGui` создаёт 54-слотовый инвентарь с собственным `Holder`, обновляет открытые меню; `CasinoGuiListener` отменяет клики и перетаскивания, не позволяя забирать предметы.
- `GuiLayout` без Bukkit задаёт точное соответствие слота типу ставки и числам. Страницы: числа/быстрые внешние; дюжины/колонки/внешние; сплит/стрит/каре/шесть номеров. У комбинаций игрок выбирает тип, при сплите ориентацию, затем допустимое начальное число.
- `ChipManager` хранит выбранный номинал отдельно для каждого игрока, `BetBook` — ставки по ключу `UUID:тип:числа`. Вторая ставка на ту же позицию того же игрока добавляется к первой; ставки разных игроков не смешиваются.

## Движение денег

GUI → `RouletteGame.placeBet` → проверка фазы/права/лимитов → `BalanceProvider.withdraw` → `BetBook.put`. При отказе деньги не списываются. Порог `max-bet` на позицию общий для всех игроков (`>=` запрещает достижение порога), `max-total-per-spin` — персональный. «Сбросить мои ставки» удаляет только ставки нажавшего и возвращает ему сумму. Закрытие GUI и выход игрока из сети не удаляют ставок.

На результате `Payout.compute` начисляет сумму × коэффициент (и ставку, если включён `return-stake-on-win`) каждому победителю отдельно через провайдер, включая офлайн UUID. После расчёта `BetBook` очищается; при штатном выключении **до** результата все ещё активные ставки возвращаются. При аварийном обрыве сервера ставки только в памяти, поэтому автоматическое восстановление после краша не предусмотрено.

`FcpBalanceProvider` берёт Coins или DCoins из FCP `EconomyService`; сначала проверяет баланс и только потом вызывает `removeCoins`/`removeDCoins`. Если FCP-сервис недоступен, `FileBalanceProvider` сохраняет тестовые балансы в `balances.yml`.

## Проверка на тестовом Paper 1.21.x

1. Запустите сервер с FCP либо fallback. Проверьте `/roulette`, `/roulette give <ник> 1000`.
2. Откройте меню двумя игроками, выберите номиналы и поставьте на одно число; убедитесь, что общая сумма позиции ограничена, но выплаты персональны.
3. Проверьте все три страницы, вертикальные и горизонтальные сплиты, невозможные крайние комбинации и красное/чёрное (по 18 чисел без зеро).
4. Проверьте сброс ставок одним игроком: его деньги возвращаются, ставки второго остаются. После закрытия ставок кнопка сброса больше не работает.
5. Дождитесь общего результата; проверьте выплаты онлайн/офлайн игроку, `return-stake-on-win`, обновление баланса и автоматическое начало следующего раунда.
6. Остановите сервер во время приёма ставок; убедитесь, что ставки возвращены. Старые блоки в мире плагин не трогает.

Для логических тестов используется `src/test/java/…` (обычно `mvn test`). Запуск через локальные стабы API не заменяет испытание на реальном Paper + FCP.
