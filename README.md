# fcp-CasinoRoulette — GUI-рулетка для FCP

Европейская рулетка для Paper 1.21.x / Java 21. **Игра целиком в инвентарном меню**: `/roulette` открывает казино. Все игроки участвуют в **одном общем раунде** и видят общий таймер и результат. В мире казино ничего не строит и не создаёт сущностей.

## Как играть

1. Введите `/roulette` (право `roulette.play`, по умолчанию есть у всех).
2. Выберите номинал в верхней строке меню.
3. На первой странице нажмите число 0–36 либо быструю ставку (красное, чёрное, чёт, нечёт, 1–18, 19–36).
4. Кнопкой «Следующая» перейдите на страницу дюжин и колонок, затем на страницу комбинаций. На странице комбинаций выберите тип (сплит, стрит, каре, шесть номеров) и нажмите **начальное** число комбинации. Сплит переключается между горизонтальным (→) и вертикальным (↓). Недопустимые начальные числа затемнены.
5. Деньги списываются сразу при принятии ставки. До закрытия приёма можно нажать «Сбросить мои ставки» — **только ваши** ставки удалятся и деньги вернутся. Во время прокрутки сброс недоступен. Закрытие меню не снимает ставку.
6. После `betting-seconds` приём ставок закрывается. В течение `spin-seconds` подсветка следует порядку европейского колеса; затем показывается одно случайное число для всех и начисляются выигрыши (в том числе вышедшим из меню и офлайн-игрокам через экономику).

**Выплаты (коэффициент выигрыша без ставки):** число ×35, сплит ×17, стрит ×11, каре ×8, шесть номеров ×5, дюжина/колонка ×2, равные шансы ×1. При `return-stake-on-win: true` выигравшая ставка дополнительно возвращается. Рулетка с одним зеро, 18 красных и 18 чёрных; анимация использует `EUROPEAN_ORDER`.

## Команды

| Команда | Право | Действие |
| --- | --- | --- |
| `/roulette` | `roulette.play` | Открыть меню |
| `/roulette balance` | — | Показать свой баланс |
| `/roulette give <онлайн-игрок> <сумма>` | `roulette.admin` | Начислить валюту |
| `/roulette set <онлайн-игрок> <сумма>` | `roulette.admin` | Установить баланс |
| `/roulette reload` | `roulette.admin` | Перечитать конфиг и номиналы |

`roulette.admin` по умолчанию только у операторов. Старые команды управления блоками отсутствуют.

## Валюта

Если FCP-EconomyMarket предоставляет `EconomyService` через FCP-Core, используются **Coins**. Ключ `fcp-currency: dcoins` выбирает донат-монеты. Никаких Vault или отдельных кошельков при работающем FCP нет. Без сервиса включается тестовый `balances.yml` (не использовать как боевую экономику); можно выдать деньги через `/roulette give`. Перед списанием FCP вызывается проверка достаточности, потому что `removeCoins` сам её не делает.

## Установка и сборка

- Сборка: `mvn -B clean package` при доступном Maven, Paper API и установленном локально FCP-Core `Frontiks:fcp-core:1.0.0` (см. `pom.xml`). Нужен JDK 21.
- Скопируйте `target/fcp-casino-roulette-1.0.0.jar` в `plugins/`, установите FCP-Core и FCP-EconomyMarket и перезапустите сервер. До запуска на сервере убедитесь в совместимости реальных сигнатур `EconomyService` с вашей версией FCP.
- Параметры длительности раунда, лимиты ставок, номиналы, сообщения и валюта — в `plugins/fcp-CasinoRoulette/config.yml`.
- Старые ключи `config.yml` сохранены для совместимости, но настройки физического отображения в GUI не применяются. **Обновление плагина не удаляет ранее построенные в мире блоки**: удалите их вручную после резервного копирования мира. Не запускайте на продакшене без проверки на тестовом сервере.

Код игры: `game/RouletteGame.java`; слоты и комбинации: `gui/GuiLayout.java`; меню и события: `gui/CasinoGui.java`, `CasinoGuiListener.java`; финансовая логика: `balance/` и `bets/`.
